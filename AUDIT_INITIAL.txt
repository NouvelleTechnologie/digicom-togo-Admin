4. L'assistant IA est masqué jusqu'au clic sur « Ouvrir l'assistant IA ».
5. L'URL Render IA précédemment inscrite dans index.html a été effacée car elle n'a pas été vérifiée et l'utilisateur demande le passage à Gemini.

POINTS BLOQUANTS AVANT PRODUCTION
1. Le backend Gemini n'est pas inclus. Les routes attendues par le frontend sont POST /api/generate-description et POST /api/improve-image.
2. Le frontend appelle getFirestore(app, 'default'). Il faut confirmer que le backend Firebase Admin utilise exactement la base Firestore nommée « default » et vérifier la structure des documents.
3. Les opérations critiques Admin écrivent directement dans Firestore depuis le navigateur. La sécurité réelle dépend des règles Firestore et/ou d'un backend d'administration ; les contrôles de rôle côté interface ne suffisent pas.
4. Il faut inspecter les règles Firestore, Storage, les fonctions de création d'utilisateur, la configuration Render et les variables d'environnement avant de déclarer le système sécurisé.
5. La clé Gemini doit être uniquement dans les variables privées du backend, jamais dans les fichiers publiés sur GitHub Pages.
